## Spot-check entries at random

Select 5–10 entries from this wiki bundle — use `wiki list` with no filters, pick a spread across domains. For each entry, check for:

- **Tags:** redundant, misspelled, or inconsistent with the base's vocabulary.
- **Missing links:** concepts, tools, or people mentioned in the body that should link to existing entries but don't.
- **Frontmatter gaps:** missing `type`, `tags`, or `timestamp`.
- **Stale content:** outdated dates, references to superseded approaches.
- **Orphaned entries:** nothing links to this entry — verify whether it should be connected or retired.

After reviewing, apply safe fixes yourself (add missing links, consolidate tags, set missing frontmatter). Flag judgment calls — things that need the user's input — in a short list at the end.

## Suggest new ideas from existing knowledge

Scan this wiki bundle for patterns, gaps, or connections that suggest directions worth exploring. Run these checks and report concrete suggestions:

1. **`wiki unresolved`**: entries that are linked to but don't exist yet. If multiple entries link to the same missing target, it's a gap everyone has noticed.
2. **Overlapping tags across domains**: entries sharing tags but living in different folders. Candidates for cross-pollination or consolidation.
3. **Recurring themes in `LEARNINGS.md`**: patterns that keep surfacing (e.g., "we keep running into auth questions") suggest a concept entry or spike worth creating.
4. **Dense tag clusters**: a group of entries sharing many tags but no connecting `index.md`. A domain that is growing but not yet organized.

Present 3–5 concrete suggestions. Be specific: "Consider creating `/ops/auth-patterns.md`: five entries reference auth but none consolidate the approach" rather than vague recommendations.

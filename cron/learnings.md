## Review LEARNINGS.md

Read `LEARNINGS.md` at the root of the knowledge base (wiki bundle) and process its entries:

1. **Group by theme**: cluster items (e.g., tag inconsistency, missing links, structural drift, stale content).
2. **Separate quick fixes from decisions**: quick fixes are things you can act on immediately without user input. Decisions require the user's call.
3. **Apply quick fixes now**: correct synced checkboxes, consolidate redundant tags, create missing entries when the path is clear.
4. **Report findings**: give the user a short summary: how many items acted on, how many need their input, and what those items are.
5. **Related entries that don't reference each other**: use `wiki backlinks` on a few entries to spot cross-links that are missing.
6. **Archive resolved items**: remove `LEARNINGS.md` entries you've acted on. Keep only active observations.

This is a health review. The goal is to turn a scratchpad into actionable improvements without requiring the user to manage it manually.
